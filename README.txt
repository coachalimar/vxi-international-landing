FINAL GITHUB PAGES PACKAGE

FILES

- assets/: all 12 optimized product images used by the page

DESIGN / FUNCTION CHECKLIST
- Full product posters are shown without cropping (object-fit: contain).
- Product names, descriptions, and store buttons appear below each image.
- Product cards use a consistent layout on desktop and mobile.
- English / Tagalog switch is included.
- Mobile navigation menu is included.
- Product buttons link to the VXI account store.
- No product prices are displayed.
- Product images are optimized WebP files.

PUBLISH ON GITHUB PAGES
1. Extract this ZIP file.
2. Open repository: coachalimar/vxi-international-landing
3. Upload index.html and the complete assets folder to the repository root.
4. Commit the changes to the main branch.
5. Open Settings > Pages and confirm deployment from main / root.
6. Open the published GitHub Pages URL and test on desktop and phone.
